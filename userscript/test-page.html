FX Pulse Hover · 识别自检页

这个页面的自检由脚本自己驱动：脚本读取每行的 data-fxph-* 属性、跑用例、把结果写回表格。 所以即使油猴沙箱不把 API 暴露给页面，自检照样能用。
最直接的「脚本到底活没活」测试：把鼠标停在下面任意虚线框里的金额上 0.3 秒，看有没有弹出小窗。
v0.2：工具栏里多了「设置面板」（悬停时间/窗口大小/默认货币/目标币种/校准记忆/主题 CSS）和「模式：简单 ↔ 详细」； 用例最后一节是混合识别——同一段文本在不同「页面画像」（文字体系比重、语言、域名、全文货币标记普查、邻近前后文）下应该判出不同币种。

  1. Tampermonkey 里这个脚本是「已启用」状态（不是草稿、不是禁用）。
  2. chrome://extensions → Tampermonkey → 详情 → 「允许访问文件网址」必须打开。这是 file:// 页面的头号原因。
  3. 脚本头部 // ==UserScript== 必须在文件的第一行第一字节：前面不能有空行、空格或 BOM，否则整段元数据失效，@match 不生效。
  4. 脚本里要有 @match file:///*（或 @include file://*）。
  5. 点 Tampermonkey 图标，看它是否列出本页。
  6. 先随便打开一个真实网站（比如 amazon.com）：如果那里能弹窗、只有本页不行，那就纯粹是 file:// 权限问题。
